DATN Portal server (172.26.0.2)
================================
This container runs the demo target:

  * employee portal login (web session cookie + CSRF)
  * profile / password management
  * webmail (inbox, sent, compose, forwarding rules)
  * JWT API (/api/token, /api/me, /api/mailbox/summary)
  * forgotten /debug/sessions and /debug/audit endpoints
  * JSONL audit log at /var/log/datn/app.jsonl

Useful commands:
  systemctl status datn-portal
  curl -s http://127.0.0.1:8000/health
  tail -f /var/log/datn/app.jsonl | jq -c \
    '{timestamp,event_type,user_id,src_ip,jti,mailbox,rule,result}'

The audit log is the evidence source for the demo. It intentionally never
contains passwords, raw tokens, Authorization headers or cookie values.

The portal runs in baseline password-change mode by default (old sessions
and tokens are not revoked). The profile page exposes a "hardened mode"
checkbox for comparison.
